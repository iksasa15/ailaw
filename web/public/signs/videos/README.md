# فيديوهات لغة الإشارة

مقاطع **MP4** لعرض مترجم الإشارة في التطبيق.

## المصدر الحالي
- لقطات واقعية مولَّدة بالذكاء الاصطناعي (وضعيات إشارة تقريبية لكل عبارة).
- ليست بديلاً نهائياً عن فيديوهات ArSL مصوّرة من موقعين معتمدين؛ يمكنك استبدال أي ملف بنفس الاسم لاحقاً.

## مواصفات الاستبدال (تصوير حقيقي)
- المدة: 2–4 ثوانٍ لكل إشارة
- الإطار: نصف الجسم + اليدين واضحين
- التصدير: `mp4` (H.264)، صامت أو بدون صوت مهم

## الملفات المطلوبة
انظر الجداول أدناه — كل الأسماء موجودة حالياً في هذا المجلد.
