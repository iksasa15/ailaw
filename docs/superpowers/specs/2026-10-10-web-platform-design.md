# مواصفات منصة «النظارة الذكية» على الويب

التاريخ: 2026-10-10 · العرض أمام الحضور: 2026-10-11 (لابتوب + عارض)

## 1. الهدف

تحويل الموقع (`web/`) من تطبيق بشكل جوال (عمود ضيق `max-w-md` وتبويبات سفلية) إلى **منصة كاملة**
تربط **الشخص الأصم** بـ**المحامي**: تصفّح المحامين، حجز جلسة، قبول المحامي، دخول جلسة مباشرة
بترجمة إشارة ↔ صوت، محضر للجلسة، ومركز لتعلّم الإشارة — مع الإبقاء على مميزات الموقع الحالية وتطويرها
(العدسة، المعمل وسيناريو الحادث، جلسة الجهازين بـ QR، التعليمات، الإعدادات، عن المشروع).

### ما قاله المستخدم
- المستخدمون: الأصم + المحامي.
- البيانات داخل المتصفح (بيانات عرض جاهزة)، بدون اعتماد على السيرفر في العرض.
- جهاز العرض: لابتوب + عارض؛ والمنصة تتكيّف مع الجوال.
- الإضافات المختارة: مركز تعلّم الإشارة، محضر الجلسة.
- النهج: إعادة البناء داخل المشروع الحالي (React + Vite + Tailwind).

### افتراضات (أكّدها المستخدم ضمنياً بقبول الفهم)
- الاسم «النظارة الذكية» بشعار النظارة والهوية التركوازية نفسها التي صُممت لتطبيق الجوال.
- العربية فقط، اتجاه RTL، خط Thmanyah Sans.
- لا حسابات حقيقية: حسابا عرض جاهزان (أصم / محامٍ) والتبديل بينهما من الشريط العلوي.

### معيار النجاح (سيناريو العرض)
1. الصفحة الرئيسية العامة تعرّف بالمنصة.
2. «دخول» كأصم ← المحامون ← صفحة محامٍ ← حجز (يوم/وقت، القضية، طريقة التواصل) ← «بانتظار التأكيد».
3. التبديل إلى المحامي ← «طلبات الحجز» ← قبول.
4. العودة للأصم ← «جلساتي» ← «ادخل الجلسة» ← غرفة الجلسة (كاميرا، إشارة، كلام، محادثة).
5. «إنهاء الجلسة» ← المحضر (ملخص + سجل كامل) ← طباعة/تنزيل.
6. مركز التعلّم: درس حرف بالكاميرا يكتمل بـ ✓.
كل ذلك على لابتوب واحد بدون سيرفر، وبدون أخطاء في الـ console.

## 2. خارج النطاق
تسجيل حسابات حقيقية، قاعدة بيانات مشتركة بين الأجهزة، دفع، إشعارات، تقييمات يكتبها المستخدم،
لوحة مشرف، مكالمة فيديو بين جهازين (جلسة الجهازين تبقى عبر غرف السيرفر الحالية كخيار إضافي).

### الغلاف (AppShell)
- شاشة ≥ 1024px: قائمة جانبية يمين (الشعار، عناصر الدور، بطاقة الحساب أسفلها) + شريط علوي
  (عنوان الصفحة، مبدّل الدور «أصم ⇄ محامٍ»، زر العدسة السريع). المحتوى بعرض أقصى 1200px.
- شاشة < 1024px: شريط علوي مضغوط + تبويبات سفلية (أهم 5 عناصر) + قائمة «المزيد».
- غرفة الجلسة والعدسة: ملء الشاشة داخل الغلاف (بدون حدود المحتوى).

قائمة الأصم: الرئيسية، المحامون، جلساتي، مركز التعلّم، العدسة، المعمل، التعليمات، الإعدادات.
قائمة المحامي: لوحتي، طلبات الحجز (مع عدّاد)، جلساتي، أوقات التوفر، العدسة، التعليمات، الإعدادات.

## 4. الصفحات

### 4.1 الصفحة الرئيسية العامة
بطل (Hero): الشعار، «النظارة الذكية»، الوعد «كلام المحامي يصبح إشارة — وإشارتك تُسمع صوتاً»،
زرّان «احجز جلسة» (← `/login`) و«جرّب العدسة» (← `/login` ثم العدسة). ثم: كيف تعمل (3 خطوات:
احجز ← ادخل الجلسة ← استلم المحضر)، المميزات (ترجمة مباشرة، محامون يفهمون احتياجك، محضر موثّق،
تعلّم الإشارة، خصوصية: المعالجة في جهازك)، محامون مميزون (3 بطاقات من البيانات)، أرقام العرض
(محامون، جلسات، دروس)، تذييل.

### 4.2 الدخول
بطاقتان: «أنا أصم/أبكم» (أحمد العتيبي) و«أنا محامٍ» (أ. سارة القحطاني). الاختيار يحفظ الدور ويفتح `/app`.

### 4.3 لوحة الأصم
بطاقة «جلستك القادمة» (المحامي، الموعد، عدّ تنازلي، الحالة، «ادخل الجلسة» إذا كانت مؤكدة)،
تقدّم التعلّم (نسبة كل دورة)، اختصارات (احجز جلسة، العدسة، المعمل)، آخر محضر.

### 4.4 دليل المحامين وصفحة المحامي
- بحث بالاسم + تصفية بالتخصص (مرور، أسرة، عمل، جنائي، عقود). بطاقة: صورة/أحرف أولى، الاسم،
  التخصصات، التقييم (من البيانات)، سنوات الخبرة، المدينة، شارة التواصل («يتقن الإشارة» أو «عبر الترجمة الفورية»)،
  «أقرب موعد».
- صفحة المحامي: نبذة، التخصصات، اللغات/التواصل، مراجعات جاهزة (عرض فقط)، والحجز بثلاث خطوات:
  1) الأيام السبعة القادمة ثم الأوقات المتاحة؛ 2) نوع القضية + وصف قصير (اختياري، ≤ 300 حرف)
  + طريقة التواصل (إشارة / كتابة)؛ 3) مراجعة وتأكيد ← حجز «بانتظار تأكيد المحامي» + رسالة نجاح.

### 4.5 جلساتي
تبويبا «قادمة» و«سابقة». بطاقة الجلسة: الطرف الآخر، الموعد، نوع القضية، الحالة (بانتظار التأكيد /
مؤكدة / مكتملة / ملغاة / مرفوضة). الإجراءات: «ادخل الجلسة» (مؤكدة)، «إلغاء» (بانتظار/مؤكدة)،
«المحضر» (مكتملة).

### 4.6 لوحة المحامي، الطلبات، التوفر
- لوحتي: جلسات اليوم، عدد الطلبات المعلّقة، أرقام (جلسات هذا الأسبوع، الموكّلون، المكتملة).
- الطلبات: لكل طلب: الموكّل، الموعد، القضية، الوصف، طريقة التواصل؛ «قبول» / «اعتذار».
- التوفر: شبكة أسبوعية (الأحد–الخميس × 9:00–17:00 كل ساعة) للتفعيل/الإلغاء؛ أوقات الحجز في صفحة
  المحامي تُحسب منها مباشرة (ناقص المحجوز، ناقص الماضي).

### 4.7 غرفة الجلسة المباشرة
- على الشاشات الكبيرة: الكاميرا كبيرة (مع هيكل اليد وشارات التتبع والنتيجة في الوسط) + لوحة جانبية ثابتة:
  المشاركان + مؤقّت الجلسة، مترجم الإشارة (فيديوهات الكلمات/الحروف)، نص كلام المحامي، المحادثة مباشرة.
- أدوات أسفل الكاميرا: استقبال، إرسال، حروف، ترجمة، أمان + زر أحمر «إنهاء الجلسة».
- جهاز واحد: نفس منطق العدسة الحالية (الكاميرا ← MediaPipe ← عبارات بالأصابع/حروف ← نطق؛
  المايك ← التعرف على الكلام في المتصفح ← نص + إشارة). المحادثة تُسجَّل محلياً لهذه الجلسة.
- «ربط جهاز ثانٍ (QR)»: يفتح تدفق الغرفة الحالي (يتطلب السيرفر)، مع تنبيه واضح إن لم يكن السيرفر متاحاً.
- «إنهاء الجلسة»: تأكيد ← يُنشأ المحضر من سجل المحادثة والمدة ← الحجز «مكتملة» ← صفحة المحضر.

### 4.8 محضر الجلسة
رأس (الشعار، «محضر جلسة»، رقم الحجز)، الأطراف، التاريخ، المدة، نوع القضية، طريقة التواصل؛
الملخص: «الوقائع» (عبارات الشخص بالترتيب، بدون تكرار) و«أسئلة المحامي وتوجيهاته» (عبارات المحامي)؛
السجل الكامل بالأوقات. «طباعة / PDF» (ورقة طباعة A4 بدون القوائم) و«تنزيل نصّاً» (.txt).
محضر «حادث مروري» مكتمل موجود في بيانات العرض.

### 4.9 مركز التعلّم
أربع دورات مع نسبة تقدّم:
1. **الحروف العربية**: كل الحروف المتوفرة صورها في `public/signs/alphabet`؛ الحروف الـ17 التي يتعرف
   عليها المتصفح (أ ب ت ث د ر ص ض ط ظ ف ق ل لا م ن ي) لها «تدرّب بالكاميرا»، والبقية «شاهد وقلّد» مع زر «أتقنته».
2. **كلمات ArSL العشر**: صورة + فيديو إن وُجد + الشرح، زر «أتقنته».
3. **عبارات القضية بالأصابع**: 1–10 لكل دور؛ التدريب بالكاميرا (عدد الأصابع المثبّت يطابق المطلوب).
4. **استخدام العدسة**: خطوات مصوّرة (من محتوى التعليمات الحالي).
الدرس: الصورة المرجعية + التعليمات + الكاميرا؛ تثبيت الإجابة الصحيحة (نفس مدة التثبيت في العدسة) ← ✓
واهتزاز/صوت نجاح ← حفظ التقدم ← «الدرس التالي».

### 4.10 الصفحات الحالية المطوَّرة
العدسة (Home الحالية داخل الغلاف الجديد بعرض كامل)، المعمل (بتصميم أعمدة للشاشات الكبيرة)،
التعليمات (أقسام في أعمدة)، الإعدادات (+ «إعادة بيانات العرض»، + اختيار الدور)، عن المشروع.

## 5. البيانات والمنطق

### 5.1 النماذج
```
User      { id, role: 'person'|'lawyer', name, city, avatar? }
Lawyer    { id, name, title, specialties: string[], city, years, rating, reviewsCount,
            signFluent: boolean, bio, reviews: {author, stars, text}[],
            availability: { [weekday 0-6]: number[] /* hours */ } }
Booking   { id, personId, lawyerId, start: ISO, durationMin: 30, caseType, description,
            channel: 'sign'|'text', status: 'pending'|'confirmed'|'completed'|'cancelled'|'declined',
            createdAt, record?: Record }
Record    { startedAt, endedAt, durationSec, entries: {role, text, at}[],
            summary: { facts: string[], lawyerNotes: string[] } }
Progress  { [courseId]: { [lessonId]: true } }
```

### 5.2 التخزين
- `web/src/platform/` : `seed.js` (6 محامين، حسابا العرض، حجوزات: معلّق، مؤكد اليوم، مكتمل بمحضر)،
  `logic.js` (دوال صرفة)، `store.js` (localStorage بمفتاح مُصدَّر الإصدار `sg-platform-v1`)،
  `PlatformContext.jsx` (السياق + الإجراءات).
- الإجراءات: `login(role)`, `switchRole()`, `book(lawyerId, start, details)`, `accept(id)`, `decline(id)`,
  `cancel(id)`, `completeSession(id, entries, startedAt)`, `toggleAvailability(weekday, hour)`,
  `markLesson(course, lesson)`, `resetDemo()`.
- مواعيد بيانات العرض نسبية لتاريخ اليوم (تُولَّد عند البذر) حتى تكون «اليوم/غداً» دائماً.

### 5.3 المنطق الصرف (مع اختبارات Vitest)
- `availableSlots(lawyer, bookings, fromDate, days, now)`: أوقات التوفر ناقص المحجوز (غير الملغى/المرفوض) ناقص الماضي.
- `transition(booking, action)`: الانتقالات المسموحة فقط (pending→confirmed/declined/cancelled،
  confirmed→completed/cancelled)؛ غيرها يُرفض.
- `buildRecord(entries, startedAt, endedAt)`: المدة، الوقائع (عبارات الشخص بلا تكرار متتالٍ)،
  ملاحظات المحامي، السجل.
- `recordToText(booking, lawyer, person)`: نص المحضر للتنزيل.
- `courseProgress(course, progress)`: النسبة.
- `nextSession(bookings, now)` و`splitSessions(bookings, now)` (قادمة/سابقة).

## 6. التصميم البصري
- الهوية: تركواز داكن `#0F766E`، فاتح `#14B8A6`، أزرق المحامي `#1E5BB8`، خلفية `#E8F1F4`، حبر `#0B1C24`؛
  شعار النظارة (عدسة يد + عدسة صوت) كـ SVG من رسم `BrandMark.swift` نفسه.
- بطاقات بيضاء بحواف 20px وظل خفيف، أزرار عريضة، عناوين Thmanyah Black، أرقام لاتينية.
- غرفة الجلسة والعدسة داكنتان (نفس لوحة تطبيق الجوال).
- الطباعة: ورقة `@media print` للمحضر.
- إتاحة: أهداف لمس ≥ 44px، تباين واضح، `aria-label` للأزرار الأيقونية، التركيز ظاهر.

## 7. الأخطاء والحالات الحدّية
- لا كاميرا / رفض الإذن: بطاقة توضيح (المكوّن الحالي `PermissionGate`).
- المتصفح بلا تعرف على الكلام (غير Chrome/Edge/Safari): «الاستقبال غير متاح في هذا المتصفح» ويستمر الإرسال.
- السيرفر غير متاح: كل المنصة تعمل؛ فقط «ربط جهاز ثانٍ» وكلمات ArSL الآلية وتحليل الأصوات تُعرض «يتطلب الخادم».
- localStorage تالف/مفقود: يُعاد البذر تلقائياً.
- حجز وقت أصبح محجوزاً/ماضياً: يُرفض برسالة ويُحدَّث العرض.
- إنهاء جلسة بلا محادثة: محضر بملاحظة «لم تُسجَّل عبارات».

## 8. الاختبار والتحقق
- Vitest للمنطق الصرف (القسم 5.3).
- `npm run build` و`npm run lint` بلا أخطاء.
- لقطات في المتصفح المدمج بعرض 1440 و390 لكل صفحة.
- تشغيل سيناريو العرض (القسم 1) كاملاً في المتصفح بدون أخطاء console.
