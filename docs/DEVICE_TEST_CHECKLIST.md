# قائمة تجربة التطبيق على الآيفون قبل العرض

التطبيق يعمل بالكامل على الجهاز — بدون سيرفر وبدون إنترنت. هذه القائمة تُجرى على جهازَي iPhone (جوال للمحامي وجوال للشخص) قبل العرض بيوم على الأقل.

## 1. قبل يوم العرض (مع إنترنت)

- [ ] افتح `AI LAW/AI LAW.xcodeproj` في Xcode، وصِل الآيفون بالكابل، واختره من قائمة الأجهزة، ثم اضغط ▶︎ Run. كرر ذلك للجوال الثاني.
- [ ] على كل آيفون: الإعدادات ← الخصوصية والأمان ← وضع المطوّر (Developer Mode) مفعّل.
- [ ] على كل آيفون: الإعدادات ← عام ← لوحة المفاتيح ← أضف **العربية** وفعّل **الإملاء**، ثم انتظر حتى تُحمَّل حزمة اللغة (مرة واحدة فقط).
- [ ] على كل آيفون: الإعدادات ← تسهيلات الاستخدام ← المحتوى المنطوق ← الأصوات ← العربية ← نزّل صوتاً (يُفضّل «محسّن»).
- [ ] افتح التطبيق وأكمل شاشة الترحيب واضغط «سماح» لكل إذن (الكاميرا، المايك، التعرف على الكلام، الشبكة المحلية).
- [ ] المزيد ← **فحص الجاهزية**: كل البنود ✓ على الجوالين (بند «الجوال الثاني» يصبح ✓ بعد الاتصال في الخطوة 3).

## 2. وضع العرض

- [ ] فعّل **وضع الطيران**، ثم أعد تشغيل **الواي فاي** و**البلوتوث** (بدون الاتصال بأي شبكة) — الربط بين الجوالين يحتاجهما فقط.
- [ ] مفتاح الصامت: لا يؤثر على النطق، لكن ارفع مستوى الصوت.
- [ ] عطّل القفل التلقائي للشاشة أثناء العرض.

## 3. جلسة الجوالين — السيناريو الكامل (`DEMO_SCRIPT.md`)

- [ ] جوال A: تبويب «جلسة» ← «أنا المحامي». جوال B: «أنا الشخص».
- [ ] انتظر «متصل بـ …» على الجوالين، ثم «ادخل شاشتي» على كل جوال.
- [ ] نفّذ الخطوات العشر:
  - المحامي يتكلم (مثلاً «أين وقع الحادث؟») ← يظهر النص على جوال المحامي، ويظهر **مترجم الإشارة بالفيديو** على جوال الشخص.
  - الشخص يرفع عدد الأصابع (1–10) ويثبّتها ثانية تقريباً ← **ينطق جوال المحامي** العبارة وتظهر بطاقة «الشخص بالإشارة».
- [ ] أغلق شاشة أحد الجوالين ثم ادخلها مجدداً ← يعود «متصل» تلقائياً.

## 4. جوال واحد — تبديل الدور

- [ ] تبويب «عدسة»: ثبّت **إصبعاً واحداً 5 ثوانٍ** ← يقول «وضع المحامي».
- [ ] ثبّت **إصبعين 5 ثوانٍ** ← يقول «وضع الشخص».
- [ ] ارفع 3 أصابع ← «الحادث عند الإشارة» في الوسط مع النطق.

## 5. وضع الحروف

- [ ] زر «حروف» ← اكتب «سلام» بتثبيت كل حرف 3 ثوانٍ (س = كف مفتوح أصابع متلاصقة، ل = إبهام + سبابة، ا = إبهام، م = قبضة).
- [ ] «إرسال» ← يُنطق النص (أو يُرسل للمحامي في جلسة الجوالين).

## 6. الأمان

- [ ] فعّل «أمان». شغّل صوت صفارة إسعاف من جهاز ثالث قريب ← **وميض أحمر + اهتزاز** وعبارة «صفارة إنذار».
- [ ] أوقف «إرسال» لتعمل الكاميرا الخلفية، وقرّب الجوال ببطء من جدار ← صفير تحذير + «احذر، حاجز قريب».

## 7. ضبط الدقة إن لزم

- اضغط مطولاً (ثانية) على شارة التتبع «وجّه يدك / يد متثبتة» ← تظهر لوحة التصحيح: النمط الخام لكل يد (مثل `01110`) والعدد والحرف المقترح.
- إذا كان العدد خاطئاً باستمرار لنفس الشكل: سجّل النمط الظاهر والإضاءة والمسافة، فالعتبات قابلة للضبط في `AI LAW/Packages/AILawCore/Sources/AILawCore/Logic/FingerCounter.swift`.
- أزرار 1–10 في لوحة التصحيح ترسل العبارة مباشرة (احتياط يوم العرض إذا تعثّر تتبع اليد).
- الإعدادات ← «حساسية التعرف» (0.35–0.40 مناسبة للعرض).
